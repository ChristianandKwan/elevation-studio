Corner rounding — consultant UI

The same real screens at four radii. Everything here is the app's own CSS; the only change is a border-radius derived from one variable. The number on each button below is the button radius — cards, panels and modals sit 2px rounder than the controls inside them, and badges 1px tighter, so nested corners stay concentric. 4px is what the Active / Archived tabs already use, so that setting makes the rest of the app agree with the one control you liked.
