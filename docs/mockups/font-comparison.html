Typography study · Elevation Studio

Three alternative font pairings, compared against Cormorant Garamond & Karla.

Each card below shows the same screen content — kicker, project title, body copy, an artwork line, total, and buttons — rendered in a different pairing. The first card is the current baseline shipping in Elevation Studio. The remaining three are alternatives that step away from the editorial-serif-on-cream lane that brand work has converged on by 2026, while preserving the gallery, considered, art-consultancy register. Open in a browser; ideally a wide screen so all four sit side by side.

How to read this. Look at the project title in each card, then the artwork names, then the total figure — those are the three places Elevation Studio leans hardest on the serif. The italic in “Living Room” also tells you a lot about each face’s personality. The strip above isolates a single word at display size for direct comparison.

What I’d look for. Spectral feels closest to the current brand without being the saturated default. EB Garamond is the most historically grounded and has the most authority — best if you want the consultancy to feel established. Source Serif 4 is the most modern and the easiest to read at small sizes; it’d be the safest if you ever extend Elevation Studio with denser data tables. None of the three is on impeccable’s 2026 reflex-reject list.

What this isn’t. A real type test wants the actual content (real client names, real artwork titles, the longest dimension string, a 32-character project name, currency rounding edge cases) and the actual breakpoints. This is a reading sample — enough to react to. If one of the three feels right, the next step is a single-page implementation in your dev branch and a five-minute test on the actual budget screen.
